# Standarisasi Lingkungan Shell Zsh dan Starship Prompt

Untuk mendukung produktivitas pengembang secara optimal, NusaOS menetapkan Zsh sebagai shell interaktif default yang dilengkapi dengan Starship cross-shell prompt. Zsh mempertahankan kompatibilitas sintaks POSIX/Bash sekaligus menghadirkan fitur autosuggestions dan syntax-highlighting cerdas, sedangkan Starship yang dikompilasi dengan Rust menawarkan rendering prompt instan (<5ms) dengan indikator status bahasa pemrograman dan git branch yang rapi tanpa overhead berat framework pihak ketiga.
