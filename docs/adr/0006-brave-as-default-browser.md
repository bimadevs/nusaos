# Pemilihan Brave Sebagai Peramban Bawaan

NusaOS membutuhkan peramban web modern dengan kinerja tinggi, kompatibilitas penuh terhadap aplikasi web/ekstensi Chrome, serta perlindungan privasi bawaan (ad-blocker dan anti-tracker). Kami memutuskan menggunakan Brave Browser menggantikan peramban tradisional seperti Firefox. Karena paket Brave (`brave-bin`) tidak tersedia di repositori resmi Arch Linux (`core`/`extra`), paket ini dimasukkan ke dalam repositori lokal (`customrepo`) NusaOS agar dapat dipasang secara konsisten saat pembuatan ISO dan instalasi sistem.
