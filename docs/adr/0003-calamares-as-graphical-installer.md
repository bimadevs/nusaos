# Penggunaan Calamares Sebagai Installer Grafis

Banyak calon pengguna Arch Linux enggan memasang sistem karena proses partisi dan instalasi terminal yang rawan salah. Kami memutuskan mengintegrasikan framework Calamares dengan penyesuaian modul branding NusaOS ke dalam Live ISO. Konsekuensinya adalah peningkatan ukuran media ISO karena dependensi toolkit Qt, namun ini memberikan pengalaman instalasi yang aman, visual, dan ramah pengguna.
