# Pemilihan Hyprland Sebagai Default Compositor

NusaOS membutuhkan antarmuka visual yang modern, estetik, dan memiliki performa sangat responsif namun tetap hemat sumber daya RAM (<600MB idle). Kami memutuskan untuk mengadopsi Hyprland (Wayland) sebagai antarmuka default ketimbang Desktop Environment konvensional (seperti GNOME atau XFCE). Trade-off yang diterima adalah kurva belajar tiling window manager, yang kami mitigasi dengan menyediakan konfigurasi keybind intuitif, bar bantuan, serta opsi toggle mode floating.
